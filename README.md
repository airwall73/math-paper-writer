# math-paper-writer

一个让 AI 写出**规范、易读、可核查**的数学证明与论文稿件的 skill 包。
为 GPT 6 Astra 设计，同样适用于其他 LLM 与 agent harness（Codex、Kimi Code 等）。
它只约束写作与核查流程，**不改变证明逻辑本身**。

## 包装内容

```
math-paper-writer.zip
├── AGENTS.md                          # 项目级指令：角色定位 + 研究优先级
└── skill-source/math-paper-writer/
    ├── SKILL.md                       # 主 skill：写作工作流
    └── references/
        ├── research-and-verification.md    # 核查与文献溯源规范
        ├── probability-journal-style.md    # 概率期刊风格样板（AOP/PTRF/EJP）
        └── example-author-style.md         # 作者风格样板（概率论某家）
```

## 主要功能

### 1. 让 AI 和"自己对账"

参考了 grill-with-docs 的设计理念，但重点不是人机对账，而是让 AI 自我审计：

- 维护一份**符号/术语台账**（`<manuscript-base>.glossary.md`，与稿件同目录）——每个符号记录含义、类型、定义位置和首次使用处；AI 自创的术语必须有对应符号与锚点，未解决的条目标记为 open
- 每个命题引用了什么，都有好找的指示：精确定理/引理/公式编号，编号冲突时主动标记而不是悄悄重排

### 2. 定义居中展示

实质性定义（尤其是带指标的对象、事件、计数变量）以居中公式展示，不藏在大段文字里；只有短而无歧义的局部别名才允许行内定义。

### 3. 文献溯源 footnotes

对驱动证明结构、关键估计或极限识别的方法，在首次实质使用处加可编译的 LaTeX footnote：

- 直接引用 → 作者、citation key、可核验的章节/定理编号，并在证明中验证条件满足
- 改编 → 说明借用了哪一步、此处改了什么、还需补什么估计
- 类比 / 独立推导 → 说明共享机制或所依赖的标准工具
- 未核实的来源标记为 pending，不假装已查证

### 4. 期刊/作者风格适配

- 内置概率期刊风格样板（基于 Annals of Probability、PTRF、Electronic Journal of Probability 共 7 篇论文的编辑风格归纳）：摘要与引言的写法、定理位置、proof roadmap、remark 的取舍等
- 内置一份作者风格样板（树上指标随机游动、分形渗流方向的某位概率学家）：证明开头如何分工、节标题命名、standing notation、常用证明连接语
- 也可换成你指定的任意期刊或作者风格；指定的风格源不可用时，会声明实际使用了哪个

### 5. 数学核查流程

- 新写或实质改动的推导**独立重算**一遍；检查渐近展开的适用区域、误差界的一致性、退化与边界情形
- 优先精确算术；依赖计算时给出可复现的脚本/命令
- 数值验证只算证据不算证明；缺口如实标记为 open

### 6. 其他约定

- **只以英文写作**（正文、footnote、台账条目），与用中文聊天讨论互不干扰
- 编号纪律：局部定义/计算用无编号公式 `\[...\]`，需要稳定交叉引用才给编号；保护已有的公式和定理编号
- 长任务维护检查点（目标、已证结果、未决命题、失败路径、下一步），中断后可无缝续作
- 主要问题未解决时，优先攻坚关键障碍，不沉迷于打磨格式和反复编译

## 使用方式

**单次使用 / 网页版**：把 zip 丢给 AI，例如

> 按这个 package 的设定，证明素数有无穷多个

**长期使用 / Codex 等 agent**：解压后放入工作区。本 package 由 `AGENTS.md` 和 skill 两部分组成——若工作区已有 `AGENTS.md`，需将两者文本合并。

## 附录：防止 Astra 偷懒

GPT 6 Astra 经常按指示前进一小步就停下，可用原生的 `/goal` 功能锁定终点，例如

```
按这个 package 的设定，进行数学推演

/goal 证明素数有无穷多个
```
