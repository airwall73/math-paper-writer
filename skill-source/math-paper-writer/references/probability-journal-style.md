# Probability journal style example

The original style notes report a seven-paper sample across Annals of Probability, Probability Theory and Related Fields, and Electronic Journal of Probability. Use these patterns as editorial preferences for a selected venue and check that venue's instructions for submission requirements.

## Abstract and introduction

- State the object and the result in present tense. Give the precise limiting law, exponent, or estimate where it is central, and name the main proof ingredients briefly. The sample uses 100–150 words as a working target when the venue and task allow.
- Introduce the model and conventions early. Give a compact quantitative account of earlier work, including the conditions under which it applies, and then identify the precise gap.
- State the main theorem formally in the introduction when appropriate to the manuscript. Place interpretation, scope, and technical restrictions near the statement they qualify. Label conjectures explicitly.
- Add a short account of the proof idea and a roadmap when they help readers navigate the paper. Put recurring notation conventions in one place.

## Proofs and closing material

- Set up the objects formally. Use a short opening paragraph for a proof section if it helps explain why the section's tool is needed. A section can be named after the theorem it proves, and auxiliary estimates can appear as lemmas.
- Lead with the formal result. Put interpretive comments and any checks that illuminate the statement into remarks. Use a short closing section only if there are remarks, checks, or open questions that belong there.
- Use active "we" and present tense for the paper's definitions and results. Attribute prior results explicitly. Cut empty transitions and unsupported novelty claims. Keep limitations and provenance when they qualify the mathematical claim.
